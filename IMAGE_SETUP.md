# Image Setup Guide for Pasindu Sathsara's Portfolio

## Required Images

Please add your images to the `public/` directory with these filenames to match the configuration:

### 1. Profile Photo
- **File**: `public/me.jpg`
- **Description**: Your professional headshot.
- **Note**: Ensure this matches the `avatarUrl` in your dashboard.

### 2. Startup/Company Logos
- **File**: `public/pazzy.jpg`
- **Description**: Pazzy Software Solutions logo.

### 3. Education Logos
- **File**: `public/jaffna.png`
- **Description**: University logo.

## Image Guidelines
- Use high-quality, professional images.
- Keep file sizes under 500KB for fast performance.
- Use PNG for logos with transparency.
- Use JPG/WebP for photographs.

## Next Steps

2. Update other logos for your specific work and education entries.
3. Use the **Admin Dashboard** at `/admin` to update the image paths if they vary.
